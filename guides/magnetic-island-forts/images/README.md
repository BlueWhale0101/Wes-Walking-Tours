Optional stop images for this guide go here.

Use real image files in stop `images` entries, for example:

```json
{
  "src": "images/gun-emplacement.jpg",
  "alt": "Concrete gun emplacement on the Magnetic Island Forts Walk",
  "caption": "Gun emplacement remains near the upper fort complex."
}
```

Do not put ordinary web page URLs in `images`; use `references` for those.
